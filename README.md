 Sobre o Projeto:

O projeto consiste em uma tabela com a lista dos 6 países mais populosos do mundo, contendo posições, bandeiras/imagens de identificação e estimativas populacionais.

O que foi praticado:

*Estruturação de Tabelas (<table>):
*Uso de <caption> para definir o título/descrição da tabela.
*Uso de <tr> para definição de linhas e <th> / <td> para células de cabeçalho e dados.
*Mesclagem de colunas através do atributo colspan (utilizado na célula de fonte dos dados).
*Inclusão de Mídias em Tabelas: Inserção de imagens (<img>) ao lado do texto dentro de células de dados para representação dos países.
*Atributos de Acessibilidade: Aplicação do atributo alt nas imagens para descrever os elementos visuais.
